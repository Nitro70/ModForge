Pictures go in this folder, as PNG files with the same path and name as the game's own.

  textures/item/diamond_sword.png      the diamond sword in the inventory and in the hand
  textures/block/stone.png             every side of a stone block
  textures/entity/creeper/creeper.png  the creeper's skin
  textures/gui/...                     menus and the HUD
  textures/painting/...                paintings

A picture replaces the game's one when the path and name are exactly the same. Names use lower case
letters, digits and underscores only. Item and block pictures are 16 by 16 pixels by default; multiples
(32, 64, ...) work as long as the picture stays square.

To see the game's own files and their names, open the game jar with a zip tool:
  .minecraft/versions/<version>/<version>.jar, then assets/minecraft/textures

After changing a picture, press F3+T in game to reload the packs.
